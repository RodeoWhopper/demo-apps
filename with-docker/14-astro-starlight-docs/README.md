# Kestrel CLI — developer documentation (Astro + Starlight)

Documentation site for **Kestrel**, a fictional single-binary CLI for preview environments. Built with **Astro 5** and the **Starlight** documentation theme: markdown/MDX pages in `src/content/docs/`, a configured sidebar, a custom logo and accent palette, a Starlight `splash` landing page at `/`, and **built-in full-text search powered by Pagefind** that is generated only at build time as static files under `dist/pagefind/`. What makes it distinct for deployment: it is a purely static site whose search only works if the whole `dist/` folder (including `/pagefind/`) is served as-is — there is no server, no SPA fallback and no environment configuration.

## Stack
- Astro 5.18.2, TypeScript 5.9.3 (strict tsconfig)
- @astrojs/starlight 0.37.7 (latest release supporting Astro 5; 0.38+ requires Astro 6/7) — includes Pagefind search, dark/light theme, sitemap
- Content: 9 docs pages in `src/content/docs/` (splash home, Getting started, Installation with tabs, Configuration, CLI reference, 3 guides, Changelog)
- Custom logo `src/assets/logo.svg`, accent palette `src/styles/custom.css`, edit links disabled, "last updated" disabled
- Docker: multi-stage `node:22-alpine` build → `nginx:1.27-alpine`

## Ports
| Port | Purpose |
|------|---------|
| 4314 | `astro preview` (serves `dist/`) / nginx in Docker; also the `astro dev` port |

## Quick start (local)
```sh
cd 14-astro-starlight-docs
npm ci
npm run build                                # writes dist/ and the Pagefind index
npm run preview -- --port 4314 --host        # http://localhost:4314
# development (search is NOT available in dev mode; only after a build):
npm run dev                                  # http://localhost:4314
```

## Docker
```sh
docker build -t kestrel-docs .
docker run --rm -p 4314:4314 kestrel-docs
curl -i http://localhost:4314/                    # 200
curl -i http://localhost:4314/getting-started/    # 200
curl -i http://localhost:4314/nope                # 404 with Starlight's 404 page
```
`nginx.conf` uses `try_files $uri $uri/ =404` with `error_page 404 /404.html` — no SPA rewrite.

## Routes
| path | method | auth required? | description |
|------|--------|----------------|-------------|
| `/` | GET | no | Splash landing page (hero + cards) — health check target |
| `/getting-started/` | GET | no | Getting started guide |
| `/installation/` | GET | no | Installation (tabbed: script, Homebrew, npm, Docker) |
| `/configuration/` | GET | no | `kestrel.toml` reference tables |
| `/reference/cli/` | GET | no | CLI command/flag/exit-code reference |
| `/guides/preview-environments/` | GET | no | Guide |
| `/guides/ci-integration/` | GET | no | Guide |
| `/guides/secrets-management/` | GET | no | Guide |
| `/changelog/` | GET | no | Release notes |
| `/404.html` | GET | no | Starlight 404 page, served by nginx for unknown paths |
| `/pagefind/*` | GET | no | Search index + UI assets (must be served statically) |
| `/sitemap-index.xml` | GET | no | Sitemap generated by Starlight |

Paths without a trailing slash (e.g. `/getting-started`) are served directly by `astro preview` (200) and redirected (301) to the slashed form by nginx.

## Data / persistence
None. All content is markdown/MDX in the repository; the search index is static files produced by the build. Theme choice is stored in the visitor's `localStorage` by Starlight.
